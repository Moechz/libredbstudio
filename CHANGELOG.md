# Changelog

All notable user-visible changes to the libredb-studio TOS application package.

## 1.2.0-1 — 2026-11-11

### Added
- First release. libredb-studio (`libredb/libredb-studio:1.2.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8071 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/libredbstudiodocker/`.
